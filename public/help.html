Connections

A few details make setup smoother.

Connect Navidrome

Enter the full HTTPS address of your Navidrome server, then your username and password. The server must allow the Volta site origin through CORS. If Volta is loaded over HTTPS, your server needs HTTPS too.

Use local files

Choose This device on the sign-in screen and select a music folder. Files are read by your browser and are not uploaded by Volta. Server playlists and scrobbling are not available in this mode.

Sign-in storage

Your password is not saved. If you choose Remember this sign-in, Volta keeps a signed Navidrome auth token in this browser profile. Use that option only on a device you control.

Share music

Choose Apple Music or Spotify in Settings. Apple Music looks for an exact catalog match. Spotify copies a provider search link so the recipient can choose the matching release.

Song credits

Open a song’s details and select Find credits. Volta then searches MusicBrainz using that song’s title and artist. Credits can be incomplete or unavailable.

Playback

Keep the signal clean.

Volta plays through the browser, with a few settings for quality and extra services.

Playback quality

Original requests the source file. Compatible requests MP3 up to 320 kbps for wider browser support. ALAC files may use Volta’s local decoder when the browser cannot play them natively.

Lyrics

Volta tries server lyrics first. If you enable external lyrics in Settings, LRCLIB may receive the current title, artist, album, and duration when your server has no lyrics.

Downloads

Volta does not download or cache your library for offline playback. Browser buffering may let a currently playing track continue briefly when a connection changes.

Still stuck?

Check your server address, CORS settings, and browser console first. If you still need help, join the Volta Discord with the error message and the steps that led to it.
